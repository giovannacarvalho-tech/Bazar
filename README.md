# Sistema Bazar

O **Sistema Bazar** é uma aplicação web desenvolvida em Java com Spring Boot para gerenciar doações de produtos entre órgãos fiscalizadores e instituições donatárias. O sistema permite o gerenciamento de lotes, produtos e entregas, facilitando a organização e o acompanhamento das doações. Utiliza MySQL para armazenamento dos dados e JDBC tradicional para a comunicação com o banco de dados.
